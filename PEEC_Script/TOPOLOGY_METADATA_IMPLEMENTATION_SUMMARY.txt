================================================================================
FIELD NAMING CONVENTIONS
================================================================================

Pattern 1: Nested Structures (with _ separator)
  inputVoltage_minimum   → .minimum
  inputVoltage_maximum   → .maximum
  inputVoltage_nominal   → .nominal

Pattern 2: Direct Fields
  diodeVoltageDrop
  currentRippleRatio
  efficiency

Pattern 3: Indexed Fields (for multiple outputs)
  outputVoltages_0       -> output 1
  outputVoltages_1       -> output 2
  outputVoltages_2       -> output 3
  outputVoltages_3       -> output 4
  Same for outputCurrents_0, _1, _2, _3

Pattern 4: Single-Output Fields (Buck/Boost)
  outputVoltage          (not indexed)
  outputCurrent          (not indexed)

All field names use snake_case for consistency.
