1. BASE CLASS ENHANCEMENTS (TopologyCalculator)
   - Added 4 waveform helper methods to generate standard waveform shapes
   - Added abstract build_waveform_preview() method for subclass overrides
   - Each helper returns dict: {"time": [...], "data": [...]}

   Helper Methods:
   a) _create_rectangular_waveform(pp, freq, duty, offset)
      - 4 time points: [0, D*T, D*T, T] where T = 1/freq
      - Data: high during on-time [0, D*T], low during off-time [D*T, T]
      - Used for: primary voltage, rectangular current

   b) _create_triangular_waveform(pp, freq, duty, offset)
      - 3 time points: [0, D*T, T]
      - Data: ramps [min, max, min]
      - Used for: triangular ripple currents in buck/boost/isolated topologies

   c) _create_flyback_primary_waveform(pp, freq, duty, offset)
      - 4 time points: [0, D*T, D*T, T]
      - Data: [min, max, min, min] showing ramp-up then jump-down at turn-off
      - Used for: flyback primary current only

   d) _create_custom_waveform(time, data)
      - Pass-through for arbitrary waveforms
      - Reserved for future advanced waveform types

2. TOPOLOGY-SPECIFIC IMPLEMENTATIONS

   All 9 topologies override build_waveform_preview(design_reqs, op, fsw):

   TwoSwitchForwardCalc:
   - Primary: RECTANGULAR voltage + RECTANGULAR current
   - Secondaries (1-4): SECONDARY_RECTANGULAR voltage + RECTANGULAR current
   - Winding count: 2-5

   SingleSwitchForwardCalc:
   - Primary: RECTANGULAR voltage + RECTANGULAR current
   - Secondaries (1-4): SECONDARY_RECTANGULAR voltage + RECTANGULAR current
   - Demagnetization: RECTANGULAR voltage + RECTANGULAR current (off-time)
   - Winding count: 3-6

   ActiveClampForwardCalc:
   - Primary: RECTANGULAR voltage + RECTANGULAR current
   - Secondaries (1-4): SECONDARY_RECTANGULAR voltage + RECTANGULAR current
   - Same waveforms as two-switch forward
   - Winding count: 2-5

   FlybackCalc:
   - Primary: RECTANGULAR voltage + FLYBACK_PRIMARY current (ramp up, jump down)
   - Secondaries (1-4): SECONDARY_RECTANGULAR voltage + FLYBACK_SECONDARY current
   - Winding count: 2-5

   PushPullCalc:
   - Primary: RECTANGULAR voltage (2x Vin) + RECTANGULAR current
   - Secondaries (1-4): SECONDARY_RECTANGULAR voltage + RECTANGULAR current
   - Winding count: 2-5

   BuckCalc (Non-isolated):
   - Inductor: RECTANGULAR voltage + TRIANGULAR current
   - Winding count: 1

   BoostCalc (Non-isolated):
   - Inductor: RECTANGULAR voltage + TRIANGULAR current
   - Winding count: 1

   IsolatedBuckCalc:
   - Primary: RECTANGULAR voltage + TRIANGULAR current (on-time)
   - Secondaries (1-4): RECTANGULAR voltage + TRIANGULAR current (on-time)
   - Winding count: 2-5

   IsolatedBuckBoostCalc:
   - Primary: RECTANGULAR voltage + TRIANGULAR current (on-time, energy storage)
   - Secondaries (1-4): RECTANGULAR voltage + TRIANGULAR current (off-time, energy transfer)
   - Winding count: 2-5

================================================================================
WAVEFORM LABEL MAPPING
================================================================================

C++ WaveformLabel types used per topology:

RECTANGULAR
- Used for: voltage in most topologies, rectangular current shapes
- Time points: 4 [0, D*T, D*T, T]
- Represents: constant high/low levels with discontinuous transitions

SECONDARY_RECTANGULAR
- Used for: secondary winding voltages in isolated topologies
- Time points: 4 [0, D*T, D*T, T] during primary on-time or off-time
- Represents: rectified/switched output from transformer secondary

TRIANGULAR
- Used for: inductor current ripple in buck/boost/isolated-buck
- Time points: 3 [0, D*T, T]
- Represents: linear ramp-up during charge, ramp-down during discharge

FLYBACK_PRIMARY
- Used for: primary current in flyback topology only
- Time points: 4 [0, D*T, D*T, T]
- Represents: linear ramp during on-time, abrupt jump at turn-off

FLYBACK_SECONDARY
- Used for: secondary current in flyback topology only
- Time points: 3 [0, (1-D)*T, T]
- Represents: triangular ripple during energy transfer phase
