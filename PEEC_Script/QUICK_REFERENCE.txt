================================================================================

1. TIW Wire Support

   - Graceful fallback to standard wire

2. Global Insulation Parameters
   - insulation_standard (e.g., "IEC 60664-1")
   - insulation_class (e.g., "basic")
   - allow_insulated_wire flag
   - allow_margin_tape flag
   - tape_kv_per_mm rating

   - Configurable thickness (default 0.05mm)
   - Symmetrical margins (top, bottom, left, right)
   - Automatically applied to winding sections

HOW TO USE IN GUI
================================================================================

1. Select Wire Insulation Type
   a. Open interactive_winding_designer
   b. Select winding tab
   c. Choose "Wire Insulation" dropdown: "TIW" or "Standard"

2. Set Global Insulation
   a. Set "Insulation Class" dropdown
   b. Select "Insulation Standard" radio button
   c. Configure margin tape (thickness, layers)

3. Visualize
   a. Click "OpenMagnetics View"
   b. System attempts TIW lookup if selected
   c. Falls back to standard wire if TIW not found
   d. Margin tape spacing applied if enabled
