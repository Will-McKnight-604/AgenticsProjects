CORE FUNCTIONS
--------------

get_topology_metadata(topology_key)
  Input:  topology_key string ('two_switch_forward', 'flyback', etc.)
  Output: metadata struct with display_name, is_isolated, n_outputs_min/max,
          required_fields, optional_fields
  Usage:  metadata = get_topology_metadata('flyback');

get_visible_fields_for_topology(topology_key)
  Input:  topology_key string
  Output: [required_fields, optional_fields] cell arrays
  Usage:  [req, opt] = get_visible_fields_for_topology('buck');

get_topology_output_type(topology_key)
  Input:  topology_key string
  Output: 'single' or 'multi'
  Usage:  type = get_topology_output_type('push_pull');  % returns 'multi'

update_field_visibility(fig, topology_key)
  Input:  fig handle, topology_key string
  Output: Updates GUI field visibility
  Usage:  update_field_visibility(fig, 'flyback');
  Note:   MAIN FUNCTION - call this when topology changes

rebuild_output_spec_table(fig, topology_key)
  Input:  fig handle, topology_key string
  Output: (Future) Rebuilds output rows
  Usage:  rebuild_output_spec_table(fig, data.topology);
  Note:   Currently placeholder, enhanced in future

collect_gui_field_values(fig, topology_key)
  Input:  fig handle, topology_key string
  Output: struct with field names and user-entered values
  Usage:  values = collect_gui_field_values(fig, 'two_switch_forward');

TOPOLOGY CATEGORIES
-------------------
ISOLATED (has transformer):
  - Two-Switch Forward    (two_switch_forward)
  - Single-Switch Forward (single_switch_forward)
  - Active Clamp Forward  (active_clamp_forward)
  - Flyback               (flyback)
  - Push-Pull             (push_pull)
  - Isolated Buck         (isolated_buck)
  - Isolated Buck-Boost   (isolated_buck_boost)

NON-ISOLATED (inductor-based):
  - Buck                  (buck)
  - Boost                 (boost)

COMMON USAGE PATTERNS
---------------------

Pattern 1: When topology changes
    function cb_topology_changed(src, ~)
        fig = gcbf();
        data = guidata(fig);
        data.topology = <get selected topology key>;
        guidata(fig, data);
        update_field_visibility(fig, data.topology);  % <-- Key call
    end

Pattern 2: Getting topology info
    metadata = get_topology_metadata(data.topology);
    if metadata.is_isolated
        % Show transformer-related fields
    end

Pattern 3: Building config from GUI values
    values = collect_gui_field_values(fig, data.topology);
    config.converter.inputVoltage_min = values.inputVoltage_min;
    % ... etc

Pattern 4: Checking output capability
    type = get_topology_output_type(data.topology);
    if strcmp(type, 'multi')
        % Show N outputs spinner
    end

TROUBLESHOOTING
---------------

Q: Fields not updating when I change topology
A: Make sure guidata(fig, data) is called BEFORE update_field_visibility()

Q: N outputs spinner not showing for some topologies
A: Check that topology is in the 'is_isolated' list in metadata

Q: Optional fields not visible
A: Check that data.show_optional is being set to true in cb_toggle_optional()

Q: Function not found errors
A: Make sure topology_field_visibility_system.m is in MATLAB path
   Try: addpath(pwd); or copy to same directory as topology_wizard.m

Q: GUI hangs when changing topology
A: Avoid infinite loops in callbacks. Make sure update_field_visibility()
   doesn't call callbacks that call update_field_visibility() again
