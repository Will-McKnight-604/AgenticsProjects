================================================================================
TOPOLOGY SUPPORT
================================================================================

All 9 topologies supported:

Isolated Topologies:
  - Two-Switch Forward (continuous primary current)
  - Single-Switch Forward (requires demagnetization)
  - Active Clamp Forward (extended voltage range)
  - Flyback (high power density)
  - Push-Pull (symmetric drives)
  - Isolated Buck (transformer plus inductor)
  - Isolated Buck-Boost (universal input)

Non-Isolated Topologies:
  - Buck (step-down)
  - Boost (step-up)

Topology Keys (snake_case to MAS format kebab-case):
  - two_switch_forward → two-switch-forward

TROUBLESHOOTING QUICK REFERENCE
================================================================================

Error: "PyOpenMagnetics not found"
  Solution: pip install PyOpenMagnetics

Error: "Invalid topology key"
  Solution: Check topology_key is snake_case (e.g., 'two_switch_forward')

Error: "Input JSON missing topology"
  Solution: Verify build_mas_structure output has all required fields

Error: "process_inputs() returned None"
  Solution: Check MAS JSON structure against PyOpenMagnetics schema

Error: "Script timeout"
  Solution: Use STANDARD_CORES instead of ALL_CORES, reduce max_results

See BUILD_MAS_README.md or MAS_API_INTEGRATION.md for complete guide
