OVERVIEW
========

The topology metadata system provides a centralized registry for all 9 converter
topologies and their associated field requirements, constraints, and display
properties.

This system is used by the GUI (topology_wizard.m) to:
  - Define topology-specific field requirements
  - Manage field visibility and constraints
  - Generate GUI controls dynamically
  - Map fields to MAS JSON structure
  - Validate user inputs

File: topology_metadata.m (14 KB, 387 lines)
Purpose: Central registry of all topology and field definitions
Key Content:
  - TOPOLOGY_DEFINITIONS struct with all 9 topologies
  - FIELD_METADATA struct with all 27 fields
  - Persistent caching for O(1) performance
Usage: Internal - called by getter functions via persistent cache

File: get_topology_metadata.m (1.6 KB, 50 lines)
Purpose: Get complete metadata for a specific topology
Signature: topo_meta = get_topology_metadata(topology_key)
Input: topology_key - string like 'two_switch_forward'
Returns: struct with:
  - display_name: 'Two-Switch Forward'
  - mas_filename: 'forward.json'
  - output_type: 'multi' or 'single'
  - required_fields: cell array
  - optional_fields: cell array
Example:
  topo = get_topology_metadata('flyback');
  disp(topo.display_name);  % 'Flyback'

File: get_field_metadata.m (1.4 KB, 51 lines)
Purpose: Get metadata for a specific field
Signature: field_meta = get_field_metadata(field_name)
Input: field_name - string like 'switchingFrequency'
Returns: struct with:
  - label: 'Switching Frequency'
  - unit: 'kHz'
  - data_type: 'number'
  - default: 200
  - min: 10
  - max: 10000
  - tooltip: Help text
  - mas_path: 'inputs.operatingPoints(1).switchingFrequency'
  - optional: false
Example:
  meta = get_field_metadata('diodeVoltageDrop');
  fprintf('Range: [%g, %g] %s\n', meta.min, meta.max, meta.unit);

File: is_field_required.m (1.4 KB, 50 lines)
Purpose: Check if a field is required for a given topology
Signature: required = is_field_required(topology_key, field_name)
Input: topology_key, field_name - strings
Returns: boolean - true if required, false if optional
Example:
  if is_field_required('flyback', 'efficiency')
      disp('Efficiency is REQUIRED for flyback');
  end

File: get_visible_fields_for_topology.m (1.5 KB, 48 lines)
Purpose: Get all fields (required + optional) for a topology
Signature: [req, opt] = get_visible_fields_for_topology(topology_key)
Input: topology_key - string
Returns:
  - req: cell array of required field names
  - opt: cell array of optional field names
Example:
  [req, opt] = get_visible_fields_for_topology('two_switch_forward');
  disp(req);  % Lists all required fields

File: get_topology_output_type.m (1.4 KB, 45 lines)
Purpose: Check if topology supports single or multi output
Signature: output_type = get_topology_output_type(topology_key)
Input: topology_key - string
Returns: 'single' or 'multi'
Example:
  if strcmp(get_topology_output_type('buck'), 'single')
      disp('Buck supports only single output');
  end
